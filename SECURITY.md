# Security Policy

## Supported versions

The current `main` branch is supported.

## Data handling

This project is a synthetic portfolio prototype. It must not contain:

- Customer records, raw warehouse extracts, PII, PHI, payment data, or confidential account data.
- Private table schemas, lineage exports, data catalog dumps, BI extracts, or access policies.
- API credentials, SSH keys, passwords, warehouse tokens, or deploy secrets.

## Reporting

Open a GitHub issue for non-sensitive security concerns. Contact the repository owner privately for sensitive issues.
